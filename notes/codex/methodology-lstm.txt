$\textbf{LSTM Architecture}$ (paper-ready)

To model the structure of the generated sequences we train an LSTM with a single learned embedding layer ($64$ dimensions), one $128$-unit recurrent layer, and a linear readout matching the vocabulary size. Training proceeds with teacher forcing on $16$-token windows using cross-entropy loss, Adam (learning rate $10^{-3}$), batch size $128$, and gradient clipping at $1.0$. Each dataset is split $90/10$ for train/validation; the held-out test split monitors final generalization. We checkpoint the parameters with the lowest validation loss and reuse that snapshot for every downstream probe. Gradient-based probes accumulate gradients only through the embedding and LSTM blocks, so both the loss-based and gradient-based evaluations share an identical architecture and optimization setup.
